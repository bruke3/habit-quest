# habit-quest
Habit Quest ⚔️🔥  Habit Quest is a gamified habit tracker built with HTML, CSS, and JavaScript.  Instead of simply checking off habits, users earn experience points (XP) for completing activities such as reading, working out, and coding. As XP increases, the player levels up, turning personal growth into a fun RPG-style experience.
